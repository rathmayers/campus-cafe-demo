# Campus Café: before/after teaching demo (CM-501)

The same fictional café website, built twice with **Astro + Tailwind CSS**:

| Path | Version |
|------|---------|
| `/` | Neutral landing page (links to both versions) |
| `/before/` | **Deliberately bad**: problems for all six lenses (content & UX, visual design, responsiveness, accessibility, performance, security & privacy) |
| `/after/` | **Fixed**: semantic HTML, WCAG 2.2 AA, responsive, optimised images, self-hosted fonts, no trackers, CSP |

All planted problems and their fixes: `teaching-material/session-01/demo-answer-key.md`.

> ⚠️ The "before" version contains fake tracking cookies and a **fake** API key in its source code on purpose. Nothing is real, nothing is sent anywhere.

## Run locally

```bash
npm install
npm run dev        # http://localhost:4321  (images are generated on first run)
npm run build      # → dist/
```

Images are **generated by code** at build time (`scripts/generate-images.mjs`) so the repository stays small and there are no copyright issues. Regenerate with `npm run images`.

## Deploy

### Vercel

Import the repository (framework: Astro, build command `npm run build`). `vercel.json` adds real HTTP security headers (CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`) to the `/after/` pages.

### GitHub Pages

1. Push to a GitHub repository (branch `main`).
2. Repository → **Settings → Pages → Source: GitHub Actions**.
3. The workflow `.github/workflows/deploy-pages.yml` builds with `SITE` and `BASE` set automatically, so the site works under `https://<user>.github.io/<repo>/`.

### Teaching point: Vercel vs GitHub Pages

| | Vercel | GitHub Pages |
|---|---|---|
| Custom HTTP headers (CSP, …) | ✅ via `vercel.json` | ❌ not possible → CSP only as `<meta>` tag (no `frame-ancestors`) |
| URL | domain root | sub-path `/<repo>/` → needs `base` in `astro.config.mjs` |
| Preview deployments per branch/PR | ✅ | ❌ |
| Build | Vercel build servers | GitHub Actions (workflow file in the repo) |
| Cost / limits | Hobby plan free (non-commercial) | free for public repos |
